ລະບົບລົງທະບຽນຮັບນ້ອງ 2026-2027 (PHP 8.1+ / MySQL ຫຼື MariaDB / Bootstrap 5.3)

ວິທີຕິດຕັ້ງ (XAMPP)
1) ແຕກໄຟລ໌ນີ້ໄປໄວ້ທີ່ C:\xampp\htdocs\freshy
2) phpMyAdmin > ເລືອກຖານຂໍ້ມູນ php_la > Import > ເລືອກ schema.sql
   (ຖ້າເຄີຍ Import ແລ້ວ ໃຫ້ Drop ຕາຕະລາງເກົ່າກ່ອນ)
3) ແກ້ config.php ໃຫ້ຖືກກັບຊື່ຖານຂໍ້ມູນ, ຜູ້ໃຊ້, ລະຫັດ ແລະປ່ຽນ IP_SALT ກັບ PIN_KEY
4) ເປີດ http://localhost:8080/freshy/setup.php ຄັ້ງດຽວ ເພື່ອສ້າງບັນຊີຜູ້ດູແລ
   ແລ້ວລຶບ setup.php ທັນທີ
5) ເປີດ http://localhost:8080/freshy/

ເຂົ້າໜ້າຜູ້ດູແລ: ກົດລິ້ງ "🔒 ຜູ້ດູແລ" ລຸ່ມສຸດຂອງໜ້າ (ຫຼືໃສ່ #admin ທ້າຍລິ້ງ)
ໜ້າກວດສອບຂໍ້ມູນ ແລະ ໜ້າວົງລໍ້ ໃຊ້ "ເບີໂທ + ລະຫັດ (PIN)" (ໜ້າກວດສອບໃຊ້ລະຫັດອ້າງອິງ LV.... ແທນ PIN ກໍໄດ້)
ໜ້າຜູ້ດູແລ ໃຊ້ "ຊື່ບັນຊີ + ລະຫັດ" ແລະມີແຖບຢູ່ເມນູສະເໝີ
ຜູ້ດູແລຫຼັກລຶບປະຫວັດການໝຸນ ແລະປະຫວັດການກະທຳຂອງຜູ້ດູແລໄດ້ (ເປັນລາຍການ ຫຼືທັງໝົດ)

ບັນຊີຜູ້ດູແລເລີ່ມຕົ້ນ (ປ່ຽນລະຫັດທັນທີຫຼັງໃຊ້ງານ)
  ຊື່ main    / ລະຫັດ Ap228899  ຜູ້ດູແລຫຼັກ ມີທຸກສິດ ສ້າງບັນຊີ ເບິ່ງບັນທຶກການໝຸນ ເບິ່ງ PIN
  ຊື່ wheel   / ລະຫັດ 778899    ໝຸນວົງລໍ້ໃຫ້ນ້ອງໄດ້ຢ່າງດຽວ
  ຊື່ approve / ລະຫັດ 999999    ອະນຸມັດ / ປະຕິເສດໄດ້ຢ່າງດຽວ

ການເບິ່ງ PIN ຂອງຄົນອື່ນ
- ຕ້ອງມີສິດ "ເບິ່ງ PIN ຂອງຄົນອື່ນ" (ຜູ້ດູແລຫຼັກຕິກສິດນີ້ໃຫ້ບັນຊີອື່ນໄດ້) ກົດ 👁 ແລ້ວກົດ "ສະແດງ PIN"
- ທຸກຄັ້ງທີ່ເບິ່ງຖືກບັນທຶກໃນຕາຕະລາງ audit_log
- PIN ຖືກເກັບແບບເຂົ້າລະຫັດດ້ວຍ PIN_KEY ໃນ config.php ໃຫ້ປ່ຽນ PIN_KEY ກ່ອນໃຊ້ງານ
- ລະຫັດຂອງບັນຊີຜູ້ດູແລເບິ່ງຄືນບໍ່ໄດ້ (ເກັບແບບແຮດ) ຖ້າລືມໃຫ້ລຶບແລ້ວສ້າງໃໝ່
- ຖ້ານ້ອງລືມ PIN ຜູ້ດູແລທີ່ມີສິດແກ້ໄຂ ກົດ "ແກ້ໄຂ" ແລ້ວຕັ້ງ PIN ໃໝ່ໃຫ້ໄດ້

ໄຟລ໌
  index.html       ໜ້າເວັບ (Bootstrap 5 ຜ່ານ CDN, ຕ້ອງມີອິນເຕີເນັດ)
  assets/app.js    ໂຄດໜ້າເວັບ
  assets/style.css ສະໄຕເສີມ
  api.php          ຫຼັງບ້ານ (ກວດສິດ, ສຸ່ມ, ກັນໝຸນຊ້ຳ ຢູ່ຝັ່ງເຊີບເວີ)
  config.php       ຕັ້ງຄ່າຖານຂໍ້ມູນ
  setup.php        ສ້າງບັນຊີຜູ້ດູແລ (ລຶບຫຼັງໃຊ້)
  schema.sql       ໂຄງຖານຂໍ້ມູນ

ໝາຍເຫດ
- ນ້ອງປີ 1 ຕ້ອງຕັ້ງ PIN ຕອນລົງທະບຽນ ແລະໃຊ້ເບີໂທ + PIN ຕອນໝຸນວົງລໍ້
- ຖ້າຈະເປີດໃຫ້ຄົນນອກໃຊ້ ຄວນໃຊ້ HTTPS ແລະບໍ່ເປີດ phpMyAdmin ອອກອິນເຕີເນັດ
